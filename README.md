# UAV Inventory Manager (Система учета БПЛА и комплектующих)

**Настольное приложение для автоматизации складского и технического учета беспилотных летательных аппаратов и их компонентов.**

## Участники команды
* **Участник 1:** Лемдянов Владислав Дмитриевич
* **Участник 2:** Дорофеев Максим Игоревич

## Назначение приложения
Приложение предназначено для инженеров, операторов и сотрудников склада, работающих с парком БПЛА. Оно позволяет вести централизованную базу дронов, отслеживать остатки запчастей (моторов, регуляторов, полетных контроллеров, аккумуляторов), фиксировать историю сборки, ремонта и списания комплектующих, а также формировать отчеты о текущем состоянии парка.

## Технологический стек
* **Frontend/UI:** Windows Forms (WinForms)
* **Платформа:** .NET 10
* **СУБД:** PostgreSQL

## Инструкции для запуска пустого проекта

### 1. Требования к окружению
Перед началом работы убедитесь, что на компьютере установлены:
* **ОС Windows 11** (необходима для запуска WinForms).
* **.NET 10 SDK** (или Visual Studio 2026 с компонентом разработки классических приложений .NET).
* **PostgreSQL** (рекомендуется версия 14 и выше) и клиент для работы с БД (pgAdmin).
